## 🚀 Featured Projects

<details>
<summary><b>🧠 DineWise — AI-Powered Food Detection & Recipe Engine</b></summary>
<br/>

Multi-model AI application that identifies ingredients from food photos and
generates personalized recipe recommendations, combining Gemini and GPT-4
Vision APIs in a single inference pipeline.

| Attribute | Detail |
|---|---|
| **Stack** | Python, Streamlit, Gemini API, GPT-4 Vision, OpenCV |
| **Scale** | Tested on a 200-image real-world dataset |
| **Performance** | End-to-end pipeline: preprocessing → feature extraction → prompt-engineered generation |
| **Security** | Confidence-based filtering to reject ambiguous/low-quality inputs |
| **Impact** | Reduced incorrect ingredient matches on edge-case images |
| **Repository** | [github.com/harsh/dinewise](https://github.com/harsh) |

Built with a deliberate choice of Streamlit over Flask to prioritize rapid
prototyping and a clean single-page interaction model — enabling real-time
image upload and ingredient analysis without frontend overhead.

</details>

<details>
<summary><b>🛡️ ByteSentry — YARA-Based Malware Detection Dashboard</b></summary>
<br/>

A signature-based malware scanning tool that processes file-level data to
detect suspicious patterns using modular YARA rule sets, surfaced through a
color-coded real-time alert dashboard.

| Attribute | Detail |
|---|---|
| **Stack** | Python, YARA, Tkinter, Threat Detection |
| **Scale** | Multi-file-type signature scanning with modular rule sets |
| **Performance** | Real-time scan feedback with color-coded severity alerts |
| **Security** | Structured detection-rule classification for systematic threat prioritization |
| **Impact** | Converts raw threat data into actionable, human-readable reports |
| **Repository** | [github.com/harsh/bytesentry](https://github.com/harsh) |

Designed with an emphasis on extensibility — new detection rule sets can be
added without altering the core scanning engine, supporting iterative threat
research.

</details>

<details>

| Attribute | Detail |

| **Scale** | Functional across 10+ distinct query categories |
| **Performance** | Iteratively tuned via logged query-trend analysis |
| **Security** | SQLite-based conversation logging for auditability |
| **Impact** | Reduced incorrect responses in ambiguous edge cases |
| **Repository** | [github.com/harsh/nlp-assistant](https://github.com/harsh) |
